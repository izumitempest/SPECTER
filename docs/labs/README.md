# Labs

Four exercises for students, per spec §11.4. Each expects only this repository
and `docs/TOUR.md` — no prior knowledge of the codebase. Solutions live on a
separate `labs-solutions` branch and are never merged into `main`.

| # | Exercise | What it teaches |
| --- | --- | --- |
| 1 | **Add a RAR signature** (`52 61 72 21 1A 07 00 00`) and make its tests pass | Signature table + parser contract (§9.2). Also the §16.5 study task. |
| 2 | **Break a Merkle proof** | Pinned tree construction; why a wrong sibling breaks the root (E-03, §7.1). |
| 3 | **Cause a chain break** | Audit co-commitment and verification (§8). |
| 4 | **Add an entropy profile** | Directional, per-type entropy triage (§10.1, P-10). |

Shipped at M6-2.
